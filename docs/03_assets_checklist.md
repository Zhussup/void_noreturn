## 2. Технические требования

### Модели (FBX)

| Параметр | Требование |
|---|---|
| Единицы | метры, 1:1; Apply Scale / Rotation перед экспортом |
| Ориентация | Y-up (стандарт Unity), «лицом» в −Z, если у объекта есть лицо |
| Пивот | в основании по центру (стол — на полу, монитор — на подставке) |
| Полигоны | стол ≤ 500, кресло ≤ 1500, монитор ≤ 1200, ноутбук ≤ 800, телефон ≤ 700, пропс ≤ 500 |
| UV | без перекрытий для уникальных поверхностей; тайлинг — только стены/пол |
| Коллайдеры | отдельные простые (Box/Capsule); не использовать Mesh Collider для мебели |
| Анимации | не нужны (сценарные движения — код) |

### Текстуры

| Карта | Формат | Цвет | Размер |
|---|---|---|---|
| Albedo | PNG | sRGB | 2048 крупное, 1024 мелкое |
| Metallic/Smoothness | PNG (R = metallic, A = smoothness) | Linear | как Albedo или 512 |
| Normal | PNG | Linear | как Albedo |

- Мелкий текст, который должен читаться с 0.9 м, делается в UI-макете, а не в текстуре.
- Никаких текстур с чужими логотипами/лицами.

### Материалы

- Только **Standard shader** (Built-in RP). Никаких URP/HDRP, Shader Graph, HDRP.
- Уникальные имена `MAT_<Object>_<Part>`; переиспользовать существующие
  (`MAT_metal`, `MAT_plastic`, ...).
- Emissive — только для экранов и светильников, через `_EmissionColor` (не bloom).

### UI-экраны

| Экран | Канвас | Формат экспорта |
|---|---|---|
| GANDEX-OS «Терминал» | 1440×900 | PNG-24, фон без прозрачности |
| «Мониторинг» | 1440×900 | PNG-24 |
| Ноутбук «ОКНО» | 1200×720 | PNG-24 |

- Слоистый исходник (Figma/PSD) + PNG на каждое состояние.
- Шрифты приложить файлами в `Assets/VOID/Fonts/`.
- Динамика (глитч, КД, опечатки, прогресс) — отдельными кадрами/параметрами с описанием.

## 5. Правила сдачи

1. Файлы — в папки §1, с правильными именами и расширениями.
2. К каждому ассету — строка в таблице этого документа (можно отдельным сообщением):
   что, где лежит, статус.
3. Скриншот проверки «в кадре» для комнаты (вид с трёх станций) и для экранов
   (Play Mode на рабочей дистанции).
4. Не удалять и не переименовывать существующие ассеты сцены без согласования:
   на имена ссылаются скрипты.
5. Сторонние ассеты — только CC0/OFL, с указанием источника.
6. Сюжетные детали, которых нет в `conc.md`, — не выдумывать, выносить автору.

## 6. Финальная приёмка

- [ ] Все P0-ассеты на месте, игра проходима.
- [ ] P1-ассеты на месте или явно отложены с записью в чек-листе.
- [ ] Ни одного ассета с URP/HDRP-шейдером, чужим логотипом или неясной лицензией.
- [ ] Имена/папки/форматы соответствуют §1–4.
- [ ] Скриншоты проверки приложены.
- [ ] Пересборка сцены (VOID → «Пересобрать базовую сцену») не ломает арт.
