## Текущее состояние сборки

Реализованы **все три ночи** арки (ночи 4–5 из PDF в игру не идут):

- **Ночь 1 · «Смена»** — вертикальный срез: вход, ГАРМОНИЯ, три задачи, шаг саботажа
  `scan`, звонок Виктора, провал в 04:12, диктофон, отчёт в 07:00. Кража файлов с
  серверов коллег (`dc7_route.log`, `dc7_backup.key`, `dc7_final.key`) и продажа их
  на теневом рынке.
- **Ночь 2 · «ТЕРРА»** — в браузере терминала открывается теневой форум «ТЕРРА»
  (страница `[3]`): покупатели, офферы, прямые продажи, выборы реплик (↑↓/1..9 + ENTER).
- **Ночь 3 · «Терминальная стадия»** — страницы `[4] СТАТУС ДЦ` и `[5] НОВОСТИ`,
  три звонка Виктора, дедлайн ТЕРРА в 06:00 (`Продано 3/3` и хотя бы одна сделка
  напрямую через ТЕРРА). В 06:50 — взрыв и **титры**, иначе 07:00 — **эпилог** («Брик
  научился»).

Прогресс между ночами — роглайт, только на время сессии (без сейвов): снимок
состояния держит `Campaign`, смерть перезапускает текущую ночь, `E` на отчёте
открывает следующую. Добавлены мышь-обзор, точка прицела и действия с предметами
(`E`): навёл на телефон — нажал `E`.

**Главное меню** — показывается при запуске игры до интро ночи: `НОВАЯ СМЕНА`,
`ПРОДОЛЖИТЬ · НОЧЬ N` (появляется после первой закрытой смены), `НАСТРОЙКИ`,
`ВЫХОД`; навигация `↑↓` + `E`/`ENTER` или мышью. Смерти/отчёты/финалы внутри
сессии идут мимо меню — только `E` на финале («с самого начала») возвращает в
него. Настройки поверх меню или (`ESC` в смене) — вертикальный список
«название — ‹ значение ›», значения крутятся по кругу стрелками или мышью.

**Постэффект CRT** — шейдер `VOID/CRT_Post` на игровой камере (`CrtFilter`,
вешается из `NightDirector.BuildCrt`), включается **только в момент проверки
кибербезов** (`TickCyberbez` → `FlashCrt(0.55, 5 с)`): скан-линии, мерцание,
сдвиг сходимости RGB, прокат развёртки, «пересканирование» полос; последние
1.5 с плавно гаснет. Вне проверок кадр чистый. **Эскалация грязных логов**:
первая проверка с грязными логами — Брик извиняется (субтитр, след +15%);
вторая — внутреннее расследование, через 15 игровых минут ВИКТОР пишет про
ордер, ещё через ~9 с — смерть «ПРИШЛИ ПО ОРДЕРУ»; след ползёт и между
проверками, пока логи не почищены.
**Саундтрек** — файл `game/Assets/Resources/Music/night_theme`
(OGG/WAV/MP3), грузится через `Resources.Load`, зациклен; громкость по ночам
0.26 / 0.34 / 0.42, на смерти и финалах — тишина (см. [03_assets_checklist.md](03_assets_checklist.md)).

**Комната** — работа друга из ветки `Alauddinpart`: `Assets/VOID/Scenes/Env_Room.unity`,
префабы `Assets/VOID/Prefabs/PRB_*` и материалы `Assets/VOID/Art/Materials/MAT_*`.
Скрипт `Assets/Editor/VoidSceneBuilder.cs` открывает `Env_Room`, убирает dev-камеру,
добавляет игрока, четыре станции и `NightDirector` и сохраняет рабочую сцену
`Assets/Scenes/Office.unity`. Пересборка — меню **VOID → «Пересобрать базовую сцену
(квартира)»**; исходная сцена друга не изменяется. Экраны мониторов — 0.32 × 0.24 м,
сетка **52 × 16** при размере текста 120 % (48–56 колонок для 100–150 %), ~1.0 м от глаз. В комнате есть `Recorder` (диктофон), `WallClock`
со стрелками, которые крутит код по игровому времени, и `Phone_LED`, который
добавляет билдер; шкафа и тумбочки нет.

## Управление

| Клавиша | Что делает |
|---|---|
| при запуске | главное меню: НОВАЯ СМЕНА · ПРОДОЛЖИТЬ (появляется после закрытой ночи) · НАСТРОЙКИ · ВЫХОД; `↑↓` + `E`/`ENTER` или мышь |
| `TAB` / `Shift+TAB` | ~~убрано~~: случайные перескоки ломали набор текста на станциях |
| прицел | решает, куда идёт печать за столом: к какому монитору прицел ближе (в рамке ~55°), тот и печатает — терминал или чат; в хинте внизу показано `печать → …` |
| `F1`–`F4` | станция напрямую; повторное нажатие — взгляд в центр |
| `B` | кровать — и обратно на терминал (`E` удерживать в кровати — отдых); во время набора текста `B` — просто буква |
| мышь | обзор вокруг станции (кликов нет) |
| левый `Alt` (удерживать) | зум камеры, работает и во время ввода текста |
| `ESC` | настройки — размер текста и текста ввода (`←` / `→`, по кругу), повторно — закрыть; если открыто из главного меню — вернуться в него |
| ввод | печать команд, реплики на форуме ТЕРРА (`1..9`, `ENTER`) |
| `R` | после смерти/отчёта/финала — переиграть смену |
| `E`/`ENTER` на отчёте ночи 1–2 | закрыть смену и начать следующую |
| `E`/`ENTER` на финале | начать игру с первой ночи (через главное меню) |
| `F9` | дев-меню — читы для быстрого прохода (задачи/файлы/ТЕРРА/логи/время/смена), клавиши `1–9`, `0` — закрыть; работает и в интро ночи, удобно показывать преподавателю. Служебная клавиша — в релизной сборке убрать |
