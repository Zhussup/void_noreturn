## 1. Общие правила

В игре **два игровых экрана** на двух мониторах. Третий, ноутбук, — декор:
на нём может быть обои или погасший логин, но игрок с ним не взаимодействует.

| Параметр | Значение |
|---|---|
| Физический размер экрана | 0.50 × 0.31 м |
| Расстояние до глаз | ~0.9 м |
| Камера | FOV 45°, экран занимает большую часть кадра |
| Сетка текста | **75 колонок × 19 строк** |
| Шрифт | `DejaVu Sans Mono` (моноширинный, кириллица) |
| Высота строки | 0.0152 м |
| Поля | 0.012 м по X, 0.010 м по Y |
| Ввод | клавиатура; мышь — обзор и наведение точки, без кликов |
| Анимация | только мигающий курсор и смена текста; без скроллов и переходов |

Текст рисуется **прямо на кваде монитора** (TextMesh), а не через Canvas/HUD.
Поэтому макет должен быть сеточным: дизайнер задаёт колонки, цвета и иерархию,
а не пиксельные координаты.

### Цвета

| Роль | Терминал | Мессенджер |
|---|---|---|
| Основной текст | `#8CFFA6` (0.55, 1.00, 0.65) | `#B8E8D6` (0.72, 0.82, 0.76) |
| Приглушённый | `#3D8752` (0.24, 0.53, 0.32) | `#667A70` (0.40, 0.48, 0.44) |
| Яркий / акцент | `#DBFFE6` (0.86, 1.00, 0.90) | `#9DB3FF` (0.62, 0.70, 1.00) |
| Предупреждение | `#FFC24A` (1.00, 0.76, 0.29) | `#FFC24A` |
| Ошибка | `#FF5C5C` (1.00, 0.36, 0.36) | `#FF5C5C` |
| Фон | `#08150D` (0.030, 0.085, 0.050) | `#08100F` (0.030, 0.060, 0.065) |

Фон — почти чёрный с едва заметным цветным уклоном. Никаких обоев, градиентов,
«стекла» и теней: это служебные программы, а не современный UI.

### Иерархия

1. **Статус-строка** сверху: система, время, счётчики. Всегда на месте.
2. **Заголовок** раздела.
3. **Содержимое**: список задач / лог / сообщения.
4. **Строка ввода** — единственное место, где мигает курсор.
5. **Подсказка клавиш** снизу, приглушённая.

Никаких рамок, панелей и кнопок. Разделители — только `-` на всю ширину.

### Прицел и подпись действия

Поверх мира код рисует маленькую точку в центре экрана. Когда точка попадает
на интерактивный предмет (телефон), под ней появляется серая подпись действия:
`PICK UP` — ответить на звонок, `HANG UP` — положить трубку.

- Подпись — **не часть мониторов** и не рисуется дизайнером; она живёт в
  экранных координатах, по центру кадра.
- Серый — светлый и нейтральный, без зелёного оттенка терминала, чтобы читался
  поверх тёмного стола.
- Игрок печатает подпись (пробелы необязательны, регистр не важен): набранные
  буквы становятся белыми, остальные остаются серыми.
- Неверная буква кратко краснит всю подпись (0.25 с), набранное сохраняется.
- По полному совпадению действие выполняется, подпись исчезает.
- Пока подпись видна, нижняя подсказка клавиш скрывается, чтобы не дублировать
  ввод.

## 2. Монитор 1 — GANDEX-OS (терминал)

**Станция 0.** Служебная оболочка: вход, официальные задачи смены, служебный
терминал саботажа.

### 2.1. Состояния

| Состояние | Когда | Что на экране |
|---|---|---|
| `Login` | начало ночи | оператор, смена, строка пароля, подсказка |
| `LoginOk` | пароль принят | подтверждение, число задач, план, предупреждение о 07:00 |
| `Tasks` | основная работа | список задач, статус, план, вход в терминал |
| `Sort` | задача 1 | письмо и три варианта: PASS / PURGE / FLAG |
| `Match` | задача 2 | профиль и три ID, нужно выбрать совпавший |
| `Approve` | задача 3 | автодонос, подтверждение словом APPROVE |
| `Sabotage` | `T` | лог команд, КД кибербезов, след, строка ввода |
| `Locked` | конец смены | «СМЕНА ЗАКРЫТА» |

### 2.2. Статус-строка

```
GANDEX-OS · ДИУ-2   03:14   ЗАДАЧ 1/3   ПЛАН 0/1
-----------------------------------------------------------------------------
```

- Время — игровое, `ЧЧ:ММ`.
- `ЗАДАЧ n/m` — закрытые/всего.
- `ПЛАН n/1` — шаг саботажа текущей ночи.
- При тревоге > 55% строка становится янтарной.

### 2.3. Вход

```
ОПЕРАТОР: BRICK.E
НОЧНАЯ СМЕНА · ДИУ-2

ПАРОЛЬ:
> *****_ 

смена 1 — вход разрешён по паролю
подсказка: brick

[ENTER] войти
```

Пароль маскируется. Неверный пароль — тревога +1 и красная строка.

### 2.4. Список задач

```
ЗАДАЧИ СМЕНЫ

> 1. Сортировка входящих                              НЕ ВЫП.
  2. Сверка профиля                                  НЕ ВЫП.
  3. Автодонос                                       НЕ ВЫП.

ПЛАН: РАЗВЕДКА ДЦ-7 [0/1]

СЛУЖЕБНЫЙ ТЕРМИНАЛ — [T]

[↑↓] выбрать   [ENTER] открыть
```

Выбранная строка — белая, остальные — зелёные; закрытые — приглушённые,
статус `ВЫПОЛНЕНО`.

### 2.5. Мини-игры

Общее: вверху номер задачи и название, тело задания, янтарный вопрос,
строка ввода, подсказка `[ENTER] принять  [ESC] назад`.

**Sort** — сортировка:

```
ЗАДАЧА 1/3 · СОРТИРОВКА ВХОДЯЩИХ

От: a.volkov@...
Тема: «список неудобных запросов»

ПРИМЕЧАНИЕ: письмо содержит имена.
Решение: PASS / PURGE / FLAG

> FLAG_
```

**Match** — сверка ID:

```
ЗАДАЧА 2/3 · СВЕРКА ПРОФИЛЯ

Профиль: ДЭЛАЙЛА, отдел кадров
Кандидаты: A-4417   A-4471   A-4714

Введите ID:

> A-4471_
```

**Approve** — автодонос:

```
ЗАДАЧА 3/3 · АВТОДОНОС

Запрос: «архив 2019»
Адресат: служба режима
Нажмите APPROVE для отправки.

> APPROVE_
```

Неверный ответ — `НЕВЕРНО. ПОВТОРИТЕ.` и тревога +2. Опечатка не стирает
уже введённое, просто не добавляет символ.

### 2.6. Служебный терминал (саботаж)

```
СЛУЖЕБНЫЙ ТЕРМИНАЛ · BRICK.E
КД КИБЕРБЕЗОВ: 04:12   СЛЕД: 3%
-----------------------------------------------------------------------------
> scan
СКАНИРОВАНИЕ РЕГИОНА...
УЗЛОВ: 4. ФИЛЬТРАЦИЯ: ДЦ-7.
ДОСТУП: УРОВЕНЬ 3 + 3 КОДА.

> help
scan            сканировать регион
connect <srv>   подключиться к серверу
devs --all      коды сотрудников
logs            состояние логов
exit            выйти

> _
[help] команды   [exit] назад
```

- КД — `мм:сс`, под 60 секунд красный.
- `СЛЕД: n%` — подозрительность; после 100% приходят кибербезы.
- Лог прокручивается вверх, на экране последние 8 строк.
- Команды вводятся в нижнем регистре, но принимаются без учёта регистра.
- На ночи 1 `scan` — единственный шаг плана; `connect` отказывает до трёх кодов.

### 2.7. Состояния по ночам

| Ночь | Отличия |
|---|---|
| 1 | стандартная зелёная оболочка; план 1/1 |
| 2 | в статусе `КОД 1/3`; после получения кода — `ДОСТУП: ДЖОЭЛ` |
| 3 | `КОД 2/3`; задачи короче, тревога выше |
| 4 | оболочка белеет, зелёный уходит; часть задач уже `ВЫПОЛНЕНО` |
| 5 | вместо `ЗАДАЧ` — `ФИНАЛ`; `devs --all` подсвечен |

## 3. Монитор 2 — мессенджер ГАНДЕКСА

**Станция 1.** Корпоративный мессенджер: ГАРМОНИЯ, шеф, сотрудники, кибербезы.
Здесь задаётся вопрос о настроении и приходят «чужие» сообщения от имени Брика.

### 3.1. Структура

```
ГАНДЕКС · МЕССЕНДЖЕР   03:14
▸ГАРМОНИЯ◂  ШЕФ*  КОМАНДА  КИБЕРБЕЗОПАСНОСТЬ
-----------------------------------------------------------------------------
ВИКТОР · 03:00
Звонок на стационарный.

ГАРМОНИЯ · 03:01
Оцените настроение от 1 до 10.

ОЦЕНКА 1–10: 4_
←→ каналы   ↑↓ прокрутка   TAB сменить экран
```

- Четыре канала: **ГАРМОНИЯ**, **ШЕФ**, **КОМАНДА**, **КИБЕРБЕЗОПАСНОСТЬ**.
- Активный канал выделен `▸ … ◂`.
- Непрочитанное — `*` после имени канала.
- Сообщения: имя отправителя и время акцентом, текст ниже с отступом.
- Длинный текст переносится по словам на ширину 73 символа.
- Прокрутка — `↑↓`, каналы — `←→`.
- Входящий звонок — янтарная пометка `ВХОДЯЩИЙ ЗВОНОК` в шапке.

### 3.2. Вопрос о настроении

- Появляется после входа в терминал.
- Принимаются только цифры, максимум две.
- `ENTER` — отправить; вне диапазона 1–10 — красная подсказка.
- Ответ сохраняется как `moodStart` и **возвращается как факт** позже — ГАРМОНИЯ
  цитирует его в отчёте, даже если Брик уже не в состоянии ответить.

### 3.3. Каналы и роли

| Канал | Кто пишет | Зачем |
|---|---|---|
| ГАРМОНИЯ | бот | настроение, советы, похвала, отчёт |
| ШЕФ | Виктор | звонки, задачи, угрозы, «спасибо за смену» |
| КОМАНДА | Джоэл, Дэлайла, Куплинов | коды, отпуск, доверие, финал |
| КИБЕРБЕЗОПАСНОСТЬ | безопасность | проверки логов, тревога |

### 3.4. Состояния по ночам

| Ночь | Отличия |
|---|---|
| 1 | пусто, кроме ГАРМОНИИ и пары служебных сообщений |
| 2 | в «КОМАНДЕ» — Джоэл и его отпуск; появляется первый код |
| 3 | Дэлайла; тон сообщений зависит от доверия |
| 4 | часть сообщений отправлена «БРИК» без ведома игрока; канал ГАРМОНИИ белеет |
| 5 | «КОМАНДА» почти пуста; Куплинов; финальные сообщения перед концовкой |

## 4. Ноутбук (декор)

- Экран 0.30 × 0.18 м, крышка наклонена на −12°.
- Может показывать: тёмные обои, погасший логин, курсор в пустой строке.
- **Не интерактивен** — не станция, не ввод, не читаемый текст.
- Нужен, чтобы стол выглядел рабочим и чтобы подчеркнуть: у Брика есть вторая
  машина, к которой он не прикасается.

## 5. Обратная связь

| Событие | Визуал | Длительность |
|---|---|---|
| Опечатка | курсор заменяется на красный `▌` | 0.26 с |
| Действие доступно | серая подпись `PICK UP` / `HANG UP` под точкой прицела | пока цель в прицеле |
| Буква действия принята | буква в подписи светлеет до белого | сразу |
| Не та буква | вся подпись кратко краснеет | 0.25 с |
| Неверный пароль | красная строка, тревога +1 | 2.6 с |
| Неверный ответ | `НЕВЕРНО. ПОВТОРИТЕ.` | 2.6 с |
| Задача закрыта | `ПРИНЯТО. ЗАДАЧА ЗАКРЫТА.` | 2.6 с |
| Шаг плана | подпись в мире + сообщение ГАРМОНИИ | 3 с |
| Проверка кибербезов | строка в канале безопасности | до 07:00 |
| Звонок | янтарная шапка + пульс LED | 45 с |
| Провал | чёрная вспышка | 0.2 с |

Курсор мигает с периодом ~0.9 с (0.55 с видим, 0.35 с нет). Других анимаций нет.

## 6. Что нужно от дизайнера

1. Макеты обоих экранов **в сетке 75×19** (или в пропорции 75:19) для каждого
   состояния из разделов 2.1 и 3.
2. Палитра в hex + правила иерархии (что ярче, что приглушено).
3. Варианты шапки для ночей 1–5 (эволюция цвета и обозначений).
4. Иконки/пиктограммы — **не нужны**; если очень хочется, только текстовые
   маркеры (`>`, `*`, `▸`, `◂`, `▌`).
5. Референсы свечения и физических рамок мониторов (корпус, LED, блики).
6. Макет ноутбука-декора (только обои/погасший экран).

Макеты сдаются слоями (Figma/PSD) + PNG-превью 1920×1080. Финальный текст
рисуется кодом — дизайнер не обязан отдавать текстуры шрифта.

## 7. Приёмка

- [ ] 75 символов в строке не обрезаются и не выходят за экран.
- [ ] 19 строк помещаются без наложения.
- [ ] Кириллица и символы `▸ ◂ ▌ * ↑ ↓ ← →` отображаются.
- [ ] Строка ввода всегда в одном месте; курсор виден.
- [ ] Подпись `PICK UP` / `HANG UP` читается поверх тёмного стола и не спорит
      с текстом мониторов.
- [ ] КД и след читаются без поиска.
- [ ] Состояния ночей 1–5 различимы по цвету/шапке, но остаются одной системой.
- [ ] Проверка — скриншот из Play Mode с 0.9 м, а не макет в редакторе.
