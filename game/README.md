# VOID: NO RETURN — игровой проект (Unity)

Концепт и сюжет — в `../docs/`. Здесь — Unity-проект.

## Как открыть

1. Unity Hub → **Add** → выбрать папку `game/` (editor 6000.6.0f1).
2. Проект импортируется, и **сцена собирается автоматически** (`Assets/Scenes/Office.unity`).
   Если что-то пошло не так — меню в редакторе: `VOID → Пересобрать базовую сцену (Office)`.
3. ▶ Play.

## Управление (сейчас — на этапе проверки сцены)

- **WASD** — ходьба, **Shift** — быстрее
- **Мышь** — осмотр (по концепту в релизе мышь будет убрана — см. `../docs/00_concept.md`)
- **Esc** — отпустить/захватить курсор

## Структура

```
Assets/
  Scenes/Office.unity   — единственная сцена (собирается VoidSceneBuilder)
  Scripts/PlayerController.cs
  Editor/VoidSceneBuilder.cs  — генератор сцены (запуск: меню VOID → …)
  VOID/Materials/       — материалы, создаваемые билдером
```

## Заметки под Linux

- Регистр путей важен: `Assets/Editor` и `assets/editor` — разные папки.
- Билд по умолчанию — **Linux x86_64** (Build Settings: Standalone).
- Пайплайн — **built-in** (материалы Standard): проще для курсового проекта, при желании
  позже перейдём на URP (тогда перепишем материалы).
