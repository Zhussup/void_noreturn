## Текущее состояние сборки

Реализована **Ночь 1** как вертикальный срез: вход, вопрос ГАРМОНИИ, три официальные
задачи, шаг саботажа `scan`, звонок Виктора в 03:00, провал в 04:12, диктофон в 05:30,
отчёт в 07:00, тревога/бессонница/таблетки/отдых, опечатки, КД кибербезов.
Добавлены мышь-обзор, точка прицела и действия с предметами: игрок наводит точку на
телефон и печатает серую подпись `PICK UP` / `HANG UP`. Ночи 2–5 спроектированы
в доках, но в коде пока не собраны.

**Комната** — работа друга из ветки `Alauddinpart`: `Assets/VOID/Scenes/Env_Room.unity`,
префабы `Assets/VOID/Prefabs/PRB_*` и материалы `Assets/VOID/Art/Materials/MAT_*`.
Скрипт `Assets/Editor/VoidSceneBuilder.cs` открывает `Env_Room`, убирает dev-камеру,
добавляет игрока, четыре станции и `NightDirector` и сохраняет рабочую сцену
`Assets/Scenes/Office.unity`. Пересборка — меню **VOID → «Пересобрать базовую сцену
(квартира)»**; исходная сцена друга не изменяется. Экраны мониторов — 0.32 × 0.24 м,
сетка **60 × 19**, ~1.0 м от глаз. В комнате есть `Recorder` (диктофон), `WallClock`
со стрелками, которые крутит код по игровому времени, и `Phone_LED`, который
добавляет билдер; шкафа и тумбочки нет.

## Управление

| Клавиша | Что делает |
|---|---|
| `TAB` / `Shift+TAB` | соседняя станция |
| `F1`–`F4` | станция напрямую; повторное нажатие — взгляд в центр |
| мышь | обзор вокруг станции (кликов нет) |
| `Z` (удерживать) | зум камеры |
| `ESC` | настройки — размер текста (HUD и экраны), `←` / `→`, повторно — закрыть |
| ввод | печать команд и подписей действий |
