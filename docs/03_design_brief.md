## 2. Игра в двух абзацах

**VOID: NO RETURN** — психологический хоррор на 45–60 минут про пять ночей
технаря **Брика Эда**. Он работает на корпорацию ГАНДЕКС из собственной квартиры:
корпорация фильтрует неудобную информацию и пишет автоматические доносы. Брик
хочет снести её изнутри — получить коды трёх сотрудников, взломать дата-центр
ДЦ-7 и замести следы. Первые три ночи он ещё Брик, последние две — **VOID**,
вторая личность, которая «исправляет» всё обратно.

Геймплей — клавиатура плюс мышь для обзора: кликов нет, мышь только поворачивает
голову вокруг станции и наводит точку в центре экрана на предмет. Всё остальное —
диегетические экраны и предметы. Бессонница заставляет нажатые клавиши «не
считаться». Тревога затемняет мир; если не принять таблетку или не поспать — Брик
умирает, и ночь начинается заново. КД кибербезов всегда виден на экране взлома.
Звонок стационарного телефона — триггер смены личности. Диктофон — единственная
нить, связывающая Брика и VOID.

## 3. Что изменилось относительно офисной версии

Старые доки описывали офис, три экрана и ноутбук-станцию «ОКНО». В новой версии:

- действие перенесено в **квартиру Брика**;
- **четыре станции**: терминал, мессенджер, стол с реквизитом, кровать;
- **ноутбук остаётся декором** — на нём нет игрового интерфейса;
- **двери как станции нет** — стук в дверь существует только в концовке;
- игра длится **пять ночей**, а не одну;
- экранов два: **GANDEX-OS** (терминал) и **мессенджер**.

Всё, что в старых доках противоречит этому, считать устаревшим.

## 4. Механики → следствия для дизайна

| Механика | Следствие для дизайна |
|---|---|
| Ввод: клавиатура + мышь-обзор | Кликов нет; мышь только поворачивает взгляд и наводит центральную точку. Подсказки клавиш — часть экрана |
| Действия с предметами | Навести точку на предмет → серая подпись `PICK UP` / `HANG UP`; игрок печатает её, буквы закрашиваются; по совпадению действие выполняется |
| Опечатки | Символ не принят: красный курсор `▌` на 0.26 с; ошибка видна боковым зрением |
| Тревога → затемнение | Виньетка по краям с 25%, цвета уходят; рамки — в [03_room_design.md](03_room_design.md) |
| Таблетки / отдых | Физические предметы в кадре станции «стол» и «кровать» |
| Взлом | Терминал: цели, коды, `devs --all`, КД, след |
| Кибербезы | `мм:сс` и «СЛЕД: n%» всегда на экране саботажа, под 60 с — красный |
| Звонок → VOID | Телефон — центральный реквизит стола; пульсирующий LED, звонок слышно из любой станции |
| Время 00:00–07:00 | Настенные часы и статус-строка обоих экранов |
| Пять ночей | Одни и те же экраны меняют состояние по ночам, а не заменяются |

## 5. Технические рамки (обязательно)

| Параметр | Значение |
|---|---|
| Движок | Unity **6000.6.0f1** (Unity 6) |
| Пайплайн | **Built-in Render Pipeline**, Standard/Unlit |
| Ввод | Старый Input Manager; клавиатура + мышь-обзор (без кликов) |
| Платформа | PC, приоритет — **Linux** |
| База | 1920×1080, 16:9 |
| Камера | 1-е лицо, FOV **45°**, near 0.05, far 60 |
| Игрок | Сидит за столом; глаз на 1.25 м; четыре фиксированные станции |
| Экран | 0.32 × 0.24 м, ~1.0 м от глаз, сетка 60 × 19 |
| Квартира | 4.5 × 4.0 × 2.7 м (комната друга из ветки `Alauddinpart`) |
| Масштаб | 1 юнит = 1 м |
| Модели | Low-poly, FBX, Y-up, 1:1, пивот в основании |
| Текстуры | PBR: Albedo + Metallic/Smoothness + Normal, 1024–2048 |
| Шрифты | Только OFL / свободные; на экранах — моноширинный с кириллицей |
| Текст в игре | Русский; английские команды терминала — часть сеттинга |

### Стиль

- **Референс:** S.P.L.I.T (тревога через печать, офисный ужас, потеря авторства).
- **Сеттинг:** мрачная технократия, антиутопия, корпоративный нуар.
- **Палитра:** терминал — фосфорный **зелёный**, мессенджер — холодный
  **бирюзово-серый**, тревога — **янтарь → красный**, VOID — **глитч-белый**.
- **Материалы:** дешёвая квартира, ламинат, старый пластик, кабели, бумаги.
- **Свет:** ночь; почти выключенная потолочная лампа, холодное окно, тёплая
  настольная лампа и отсветы двух мониторов. Никакого киноглянца.

## 6. Что дизайнер должен сдать

1. **Арт комнаты** уже сдан другом (сцена, префабы, материалы, свет). Дальнейшие
   правки — только по согласованию, чтобы не разойтись с его веткой. Расстановка —
   по [03_room_design.md](03_room_design.md).
2. **Макеты двух экранов** по [03_screens_design.md](03_screens_design.md): сетка,
   состояния, цвета, иерархия. Финальный текст рисуется кодом, но макет задаёт
   композицию и палитру.
3. **Экспорт** по форматам и именам из [03_assets_checklist.md](03_assets_checklist.md).

### Чего делать НЕ нужно

- Игровых меню, пауз, HUD, стрелок поверх мира. Точку прицела и серую подпись
  действия рисует код — в макетах их быть не должно.
- Мышиных кнопок и любых элементов, требующих курсора: мышь только наводит точку.
- Пост-процессинга (bloom, DOF, motion blur) — его соберём в движке.
- Виньетки/затемнения в макетах: это сценический эффект, дизайнер даёт референс.
- Текста вне физических носителей: вся информация — на экранах, часах, предметах.
  Исключение — служебная подпись действия (`PICK UP` / `HANG UP`) у прицела,
  она рисуется кодом.
- Финального лора без согласования: спорное — в список вопросов.

## 7. Сцена и контракт имён

Сцена `Assets/Scenes/Office.unity` **собирается скриптом**
`Assets/Editor/VoidSceneBuilder.cs` (меню **VOID → «Пересобрать базовую сцену
(квартира)»**) из комнаты друга `Assets/VOID/Scenes/Env_Room.unity`. Билдер
убирает dev-камеру, добавляет игрока, станции и `NightDirector`. Пересборка
**затирает ручные правки** `Office.unity`; `Env_Room.unity` не изменяется.

- Ассеты — в `Assets/VOID/Art/...` (структура в чек-листе).
- Привязка — через `VoidSceneBuilder.cs` или отдельный префаб; ручные правки
  сцены согласовывать до пересборки.
- Имена объектов — контракт. Скрипты ищут:
  `Monitor_Terminal`, `Monitor_Chat`, `Laptop`, `Phone`, `Phone_LED`, `Pills`,
  `Recorder` (запасной вариант — `Dictaphone`), `Bed`, `Desk`, `Chair`,
  `WallClock`, `Station_Terminal`, `Station_Messenger`,
  `Station_Desk`, `Station_Bed`, `Desk_LookTarget`, `Bed_LookTarget`.
  `Phone_LED` создаёт сам билдер; остальное — из комнаты друга.
  Стрелки `WallClock` крутит `NightDirector` по `GameClock`.
  Переименование — только синхронно с кодом.

## 8. Правила взаимодействия

- Один человек — один раздел: арт комнаты и макеты экранов не пересекаются.
- Каждая сдача — списком: что добавлено, куда положено, что осталось.
- Любая неоднозначность решается **до** работы; PDF — источник истины.
- Сторонние ассеты — только CC0/OFL, с указанием источника в чек-листе.

## 9. Критерии приёмки

- [ ] В кадре каждой из четырёх станций нет голых примитивов-заглушек.
- [ ] Текст на экранах читаем с ~1.0 м при FOV 45° (проверка — скриншот из Play Mode).
- [ ] КД кибербезов и таймер смены читаются мгновенно.
- [ ] Опечатка заметна за 0.2–0.3 с, но не рвёт ритм.
- [ ] Телефон и его LED видны со станции «стол»; звонок слышен с любой станции.
- [ ] Таблетки и диктофон — физические предметы, их отсутствие/перемещение заметно.
- [ ] Материалы на Standard/Unlit, без URP/HDRP.
- [ ] Имена и папки соответствуют чек-листу.
