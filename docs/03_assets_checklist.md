Сейчас вся сцена собрана из примитивов (`Box`/`Cyl`/`Quad`) в
`VoidSceneBuilder.cs`. Задача дизайнера — заменить ключевые из них на модели и
текстуры, не ломая имена и координаты.

---

## 1. Папки и имена

```
Assets/VOID/Art/
  Environment/          стены, пол, потолок, окно, дверь
  Furniture/            стол, стул, кровать, шкаф, тумбочка
  Props/                телефон, таблетки, диктофон, стакан, кружка, бумаги
  Tech/                 мониторы, ноутбук, клавиатура, мышь, кабели
  Materials/            общие материалы
  Textures/             текстуры
Assets/VOID/Audio/
  Ambience/             фон комнаты, гул техники
  SFX/                  клавиатура, звонок, диктофон, глитч
  Voice/                русские реплики (Виктор, ГАРМОНИЯ, диктофон)
Assets/VOID/Design/
  Screens/              макеты экранов (Figma/PSD + PNG)
  References/           референсы света, материалов, состояний
```

**Имена объектов сцены — контракт.** Не переименовывать:
`Room`, `Floor`, `Ceiling`, `Wall_North`, `Wall_South`, `Wall_East`, `Wall_West`,
`Window`, `Door`, `Desk`, `Chair`, `Bed`, `Wardrobe`, `BedsideTable`,
`Monitor_Terminal`, `Monitor_Chat`, `Laptop`, `Phone`, `Phone_LED`, `Pills`,
`Dictaphone`, `WallClockText`.

Новые ассеты — дочерними объектами этих корней либо с префиксами:
`ENV_`, `FURN_`, `PROP_`, `TECH_`, `FX_`, `SFX_`, `AMB_`, `VO_`.

## 8. Форматы сдачи

- **Модели:** FBX 2014+, Y-up, 1 юнит = 1 м, пивот в основании, без LOD.
- **Текстуры:** PNG/TGA, степень двойки (1024/2048), sRGB для Albedo, Linear для
  Metallic/Smoothness/Normal.
- **Материалы:** Standard shader; без URP/HDRP; эмиссия — только экраны, LED, окно.
- **Аудио:** WAV, 48 кГц, 16 бит; loop-точки для фонов; нормализация −16 LUFS.
- **Макеты:** Figma/PSD слоями + PNG 1920×1080; сетка 75×19 обязательна.

## 9. Приёмка

- [ ] Ассеты лежат в своих папках, имена по контракту.
- [ ] Импорт не ломает сцену: объекты на местах, станции работают.
- [ ] Материалы на Standard/Unlit, без розового.
- [ ] Текст на экранах не перекрыт моделями и рамками.
- [ ] Таблетки/диктофон/телефон физически читаются в кадре.
- [ ] Звук не клиппит, звонок слышен с любой станции.
- [ ] Лицензии приложены.
