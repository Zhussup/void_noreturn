## 2. Игра в двух абзацах

**VOID: NO RETURN** — психологический хоррор (~40–60 минут) про ночную смену технаря
**Брика Эда**, работающего на корпорацию ГАНДЕКС: корпорация фильтрует неудобную
информацию, пишет автоматические доносы и плотно работает со спецслужбами. Брик болен:
бессонница, тревожное расстройство, депрессия, раздвоение личности. Он хочет использовать
свои доступы, чтобы снести корпорацию изнутри: взламывать серверы, чистить логи, воровать
коды сотрудников.

Но ему мешает не только ГАНДЕКС. Геймплей — QTE-подобный ввод текста **без мыши**.
Бессонница добавляет опечаток (даже правильно нажатая клавиша «не считается»), тревога
затемняет экран — если не отдохнуть и не принять успокоительное, Брик умрёт. Кибербезы —
сотрудники безопасности — проверяют логи и поднимают тревогу, если следы подозрительны;
их кулдаун виден прямо на экране во время взлома. А звонок стационарного телефона
переключает личность с Брика на **VOID** — пустоту, офисного планктона, который «исправит
всё» и продаст душу корпорации.

> ⚠️ Концепт-док `conc.md` **недописан** (обрывается на фразе про конец рабочего дня).
> Недостающие детали не додумывать: помечать в сдаче как «вопрос к автору».

## 3. Механики и что из них следует для дизайна

| Механика | Следствие для дизайна |
|---|---|
| QTE-ввод команд с клавиатуры | На экранах — подсказка, что печатать, и таймер; никаких кнопок мышью |
| Бессонница → опечатки | Визуальная обратная связь: символ не принят, курсор стоит, вспышка ошибки; уровень опечаток нарастает |
| Тревога → затемнение | Мир темнеет по краям (виньетка), цвета уходят; дизайн-рамки состояний — в [03_room_design.md](03_room_design.md) |
| Отдых / успокоительное | Физические предметы: упаковка таблеток, стакан воды; отражены в декоре стола |
| Взлом серверов | Терминал: список целей, коды сотрудников, команда `devs --all`, прогресс, ошибки |
| Очистка логов | Отдельный экран/вкладка логов; визуально «грязные» и «подозрительные» записи |
| Кибербезы | **КД прямо на экране** во время взлома: обратный отсчёт, статус проверки, тревога |
| Телефон → смена личности | Телефон — центральный реквизит, всегда в кадре; световой сигнал звонка; визуальный «переход» в VOID |
| Реальное время 00:00–07:00 | Часы смены диегетичны: в статус-строке экранов; настенные часы в комнате |
| Только клавиатура | Ни одного элемента, требующего мыши; подсказки клавиш — часть интерфейса |

## 4. Технические рамки (обязательно)

| Параметр | Значение |
|---|---|
| Движок | Unity **6000.6.0f1** (Unity 6) |
| Пайплайн рендера | **Built-in Render Pipeline** (Standard shader) |
| Ввод | Старый Input Manager; мыши в геймплее нет |
| Платформа | PC, приоритет — **Linux**; Windows/WebGL опционально |
| Базовое разрешение | 1920×1080, 16:9 |
| Камера | От первого лица, FOV **45°**, near 0.05, far 60 |
| Рабочее положение игрока | Герой **сидит** за столом, глаза на высоте **1.25 м** от пола |
| Дистанция до экранов | Мониторы **~0.9 м**, ноутбук **~1.2 м** |
| Масштаб | 1 юнит Unity = 1 метр; комната 6.8 × 5.4 × 3.0 м |
| Модели | Low-poly, без LOD; FBX, Y-up, масштаб 1:1, пивот в основании |
| Текстуры | PBR: Albedo + Metallic/Smoothness + Normal; 1024–2048 px |
| Шрифты | Только OFL / свободные (Inter, IBM Plex, JetBrains Mono и т.п.) |
| Язык текстов | Плейсхолдеры на русском; финальные строки — через локализацию (RU/EN) |

### Стиль

- **Референс:** S.P.L.I.T (тревога через печать, офисный ужас, потеря авторства).
- **Сеттинг:** мрачная технократия, антиутопия, корпоративный нуар.
- **Палитра:** офисный **зелёный / янтарь / серый**; тревога — холодная синева;
  VOID — **глитч-белый**.
- **Материалы:** дешёвый корпоративный пластик, ламинат, старая техника, кабели.
- **Свет:** ночь, тёплые потолочные лампы, холодный синий от окна, отсветы мониторов.
  Никакого «киношного» глянца — только бытовая лампа и страх.

## 5. Что дизайнер должен сдать

1. **Набор арт-ассетов комнаты** (см. чек-лист): текстуры, материалы, декор;
   при необходимости — замены примитивов на модели. Расстановка — по координатам из
   [03_room_design.md](03_room_design.md).
2. **Макеты трёх экранов** (см. [03_screens_design.md](03_screens_design.md)) в слоях,
   с состояниями и шрифтами, готовые к нарезке в текстуры/RenderTexture.
3. **Финальный экспорт** по форматам и именам из [03_assets_checklist.md](03_assets_checklist.md).

### Чего делать НЕ нужно

- Игровых меню, пауз, HUD, прицела, стрелок-подсказок поверх мира.
- Кнопок и элементов, управляемых мышью.
- Пост-процессинга (bloom, DOF, motion blur) — движок соберём сами; дизайнер даёт
  материалы и макеты. Отдельно: **«затемнение от тревоги»** — это сценический эффект,
  дизайнер задаёт его визуальные рамки референсами, не рендерит в макетах.
- Текста, выходящего за пределы экранов, — вся информация только на физических носителях.

## 6. Важное про сцену

Сцена `Assets/Scenes/Office.unity` **генерируется скриптом**
`Assets/Editor/VoidSceneBuilder.cs` (меню **VOID → «Пересобрать базовую сцену»**).
Пересборка **затирает ручные правки сцены**. Поэтому:

- Арт-ассеты кладём в `Assets/VOID/Art/...` (структура — в чек-листе).
- Привязка ассетов к сцене — через правки `VoidSceneBuilder.cs` или через отдельный
  префаб/скрипт; договориться до того, как менять сцену руками.
- Имена объектов сцены — контракт: скрипты ищут объекты по именам
  (`Monitor_Terminal`, `Monitor_Chat`, `Laptop`, `Phone`, `Chair`, `Door`, ...).
  Переименование — только синхронно с кодом.

## 7. Правила взаимодействия

- Один человек — один раздел: арт комнаты и макеты экранов не пересекаются.
- Каждая сдача — списком: что добавлено, куда положено, что осталось.
- Любая неоднозначность в ТЗ решается **до** работы. Концепт недописан — спорные
  сюжетные детали выносить автору, а не заполнять догадками.
- Не использовать сторонние ассеты с неясной лицензией. CC0/OFL — можно, с указанием
  источника в чек-листе.

## 8. Критерии приёмки (общие)

- [ ] Всё, что видит игрок в кадре на станциях 1–3, выглядит цельно и без «дыр» (нет
      голых примитивов-заглушек в поле зрения).
- [ ] Тексты на экранах читаемы с расстояния 0.9 м при FOV 45° (проверка — скриншот
      из Play Mode, а не только макет в редакторе).
- [ ] КД кибербезов и таймер смены читаются мгновенно, без поиска.
- [ ] Обратная связь «опечатка не принята» заметна за 0.2–0.3 секунды.
- [ ] Материалы используют Standard shader; никаких шейдеров, требующих URP/HDRP.
- [ ] Все тексты/обозначения — плейсхолдеры, не финальный лор без согласования
      с `conc.md`.
- [ ] Ассеты соответствуют форматам, именам и папкам из чек-листа.
