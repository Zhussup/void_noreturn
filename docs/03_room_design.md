## 1. Задача

Сделать комнату ночной смены **Брика Эда**: дешёвый корпоративный кабинет ГАНДЕКС в
мрачной технократии. Комната — характер персонажа: безлично, уныло, аккуратно, но в
ней живёт человек, который не спит и сходит с ума. Следы болезни должны читаться без
текста: упаковки успокоительного, стакан воды, круги под глазами (не видно), бардак у
края стола.

Игрок видит комнату только с трёх ракурсов (сидя за столом: монитор 1, монитор 2,
ноутбук) и при поворотах головы. Приоритет:

1. **Стол и его содержимое** — 90% экранного времени.
2. **Телефон** — центральный реквизит (триггер смены личности), всегда в кадре.
3. **Стена за столом и потолок** — попадают в кадр над экранами.
4. Остальное (дверь, окно, мусорка) — видно на переходах и в катсценах.

### Состояния по психике героя (пресеты)

| Пресет | Когда | Что делать |
|---|---|---|
| **A. Норма** | Начало смены, 00:00–02:00 | Как сейчас: тёплая лампа, ровный быт |
| **B. Бессонница** | Растёт число опечаток | Лампы на 20–30% тусклее; одна мигает (0.3–1.5 Гц); холоднее; больше контраста теней |

| **D. VOID** | После звонка телефона | Стерильно: тёплый свет выключен, только белые отсветы мониторов и холод окна; в кадре — «пустота» |

программист подключает. Звонок телефона — отдельный световой сигнал: короткая пульсация

## 5. Декор и нарратив (что дизайнер делает)

Комната должна **рассказывать историю без текста**.

### Телефон — главный реквизит
- Стационарный служебный телефон на столе, ближе к левой руке; трубка на базе,
  витой шнур, кнопка удержания.
- Это **триггер смены личности**: при звонке база/трубка подсвечивается пульсацией
  (световой якорь), звонок — событие, которое игрок обязан заметить. Дизайн должен
  сделать его заметным в кадре на станции 1 и 3.
- Состояния: покой / звонок / снята трубка / после звонка (в VOID-состоянии телефон
  «слишком чистый», как новый).

### Психика героя (без текста)
- **Успокоительное**: блистер на столе, часть ячеек пуста; рядом — стакан воды.
  По мере смены пустых ячеек больше, блистеры мнутся, появляются новые упаковки.
- **Бессонница**: мусорка полна стаканчиками от кофе, кружка с недопитым кофе,
  тёмные круги под глазами не видно — зато видно дрожащую руку (если появится модель
  рук; пока — только предметы).
- **Тревога**: беспорядок у края стола, смятые бумаги, следы ногтей на кромке стола.

### Стол
- Бумаги: 2–3 листа с мелким печатным текстом (приказы, протоколы) — плейсхолдеры.
- Клавиатура: стёртые клавиши, крошки, пятно от кофе.
- Кабели: аккуратно стянуты — корпоративно; один выдернут/болтается.
- Пыль на задней панели и под мониторами.

### Стены / пол
- Постер ГАНДЕКС: абстрактный «спокойный интернет» (без крупных лозунгов).
- Настенные часы со стрелками — диегетическое время смены 00:00–07:00.
- Розетки и кабель-каналы у плинтуса.
- Потолочные лампы: старые люминесцентные панели, одна желтоватая.
- Дверь: служебная, с доводчиком, без окна; ручка-скоба; табличка с номером кабинета.

### Окно
- Ночной город: глухие силуэты зданий, ни одного «живого» огня — снаружи всё под
  контролем. Слегка видна сетка/решётка.
- Подоконник: пыль, мёртвый цветок (по согласованию).

### Мусорка
- Мятая бумага, стаканчики, пустые блистеры — деталь, читаемая в катсцене.

> Все сюжетные пропсы (телефон, таблетки, записки, коды) согласовывать с `conc.md`.

## 6. Требования к ассетам комнаты

| Тип | Требование |
|---|---|
| Модели | Low-poly: стол ≤ 500 тр., кресло ≤ 1500, монитор ≤ 1200, ноутбук ≤ 800, телефон ≤ 700, мелкий пропс ≤ 500 тр. |
| Пивоты | В основании объекта, по центру; масштаб 1:1, применён (Apply Scale) |
| Имена объектов | По контракту сцены (см. §2) |
| Коллайдеры | Простые BoxCollider/капсулы; невидимые коллайдеры для стен/мебели |
| Текстуры | Albedo (sRGB), Metallic/Smoothness (linear), Normal (linear); 2048 крупные, 1024 мелкие |
| UV | Без перекрытий для уникальных поверхностей; тайлинг допустим для стен/пола |
| Материалы | Standard shader; имена `MAT_<Object>_<Part>` |
| Освещение | Статичные объекты — static; запекание света — после согласования |
| Оптимизация | Всё, что видно из кадра героя, не должно просвечивать/отсекаться (near 0.05) |

## 7. Критерии приёмки комнаты

- [ ] Сидя за столом на станциях 1–3 в кадре нет «голых» заглушек: стена, стол,
      мониторы, ноутбук, телефон выглядят как единая сцена.
- [ ] Телефон заметен с рабочего места и его состояние (покой/звонок) читается сразу.
- [ ] Успокоительное и стакан различимы, но не отвлекают от экранов.
- [ ] Настенные часы читаются и показывают время смены.
- [ ] Обзор по горизонтали не выдаёт пустых углов и щелей между стенами/полом/потолком.
- [ ] Световые пресеты A–F переключаются без артефактов (теней, засветов).
- [ ] Ни один ассет не использует URP/HDRP-шейдеры и не требует пост-эффектов.
- [ ] Имена, папки и форматы — по [03_assets_checklist.md](03_assets_checklist.md).
